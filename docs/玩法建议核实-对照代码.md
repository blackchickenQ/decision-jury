## 真正能做的 3 件（零后端、不编数据、按优先级）

1. **裁决页补「本裁决依据以下 N 条看山笔记」** — 数据已在 localStorage 和裁决请求里，`verdict/page.tsx` 加一个列表即可。叙事感最强，且是建议 2 里唯一没做的部分。
2. **立案页玩法牌视觉升级** — 三个 mode 的结构和钩子文案现成，只改 CSS，路演一眼看出「三种玩法」。
3. **证人盲盒翻牌（可选）** — 纯 CSS 动画，成本近零；**必须保留**原卡片上的 `知乎原文 ↗` 链接可点。

## 两条边界提醒

- 这 3 件都是 **P3 前端**的活。按分工 3 号不碰队友代码，本文件只做核实与定位，不改 `app/`。1 号刚立了「不碰队友文件」的纪律，改前端前跟 P3 打个招呼。
- **别显示不存在的数据**。产品最硬的卖点就是「每条结论挂原文、搜不到就说搜不到」；一致度仪表若要上，只能上真实计数，不能上 `n≥2` 那种编出来的判定。
