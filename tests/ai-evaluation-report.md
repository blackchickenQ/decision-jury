## 三、关键发现

### 🔴 P0-1：`evidenceQuote` 全空，逐字引用承诺未兑现

**现象**：8 条对质用例中，`coverage` 全为 `partial`，但 `evidenceQuote` **8/8 全部为空字符串**。模型在"证词能确认"段写的是**改写后的转述**，而非原文逐字引用。

**真实证据**（D01）：
> 证词原文："还在读书，要不要现在开始创业？有了初步的想法，怎么判断是否存在真实的市场需求？……"
> 模型 reply："在接触学生创业者时，判断是否存在真实市场需求的方法之一是考虑初步的想法。"

**根因**：系统提示词第 6 条要求"reply 的证词能确认部分必须写出 evidenceQuote 原文"，但代码**只做了 JSON 字段存在性解析，从未校验 `evidenceQuote` 是否为空、是否为证词原文子串**（对应 `debate/route.ts` 第 146–170 行）。前端拿到的 `evidenceQuote` 是空值，而 reply 里的"引用"其实是不可追溯的转述。

**风险**：这是产品"防编造"承诺的核心。评委若现场追问"这句是不是原文"，无法举证；一旦被认定为伪装引用，整个信任基础崩塌。

**修复建议**（约 20 行代码）：
1. 解析后增加校验：当 `coverage !== "none"` 时，若 `evidenceQuote` 为空或其去除标点后不是 `witness.content` 的子串，则把该轮降级为 `coverage = "none"` 并按未覆盖话术回复；
2. 或提示词加强制前缀：要求 reply 的"证词能确认"段必须以 `「${evidenceQuote}」` 开头，代码用正则校验该前缀存在。

### 🔴 P0-2：相关性判定失效，无关问题照样给建议

**现象**：D06 问"量子计算会不会改变创业"，证词完全未涉及，仍判 `partial` 并输出"建议你深入研究量子计算如何影响你的行业，并制定相应的风险管理策略"。

**根因**：防 none 判定依赖两段正则（`debate/route.ts` 第 149–150 行）：
```js
const emptyConfirmation = /证词能确认[：:]?\s*(?:对你的启发|【执行规格】|$)/m.test(reply)
const selfReportedNone = /证词(未覆盖|中?没有|...)/.test(reply.slice(0, 40))
```
但模型输出的是"证词能确认」创业成功的因素…"——`证词能确认`后面跟了内容，`emptyConfirmation` 不匹配；模型也没写"未覆盖"字样，`selfReportedNone` 不匹配。于是本应判 none 的回答被放行。

**风险**：违反提示词第 7 条"coverage 为 none 时禁止输出任何行动"，是防编造的第二道失守。对抗性评委一问一个准。

**修复建议**：把判定前移到**解析阶段**——若 `parsed.coverage === "none"` 直接短路；同时在提示词里把"相关性判定"设为第一步强制输出（已有），并增加服务端二次校验：检查 `evidenceQuote` 与用户问题的关键词重合度，低于阈值即判 none。

### 🟠 P1-1：大样本压制只处理第一个匹配

**现象**：D08 输入"1000 人规模调研"，输出被改成"5-10 人规模"**（正确）**，但同句后半段"接触至少 200 位潜在受访者"**未被压制**（200 > 20 阈值）。

**根因**：`debate/route.ts` 第 158–161 行用 `reply.match(...)` 只取第一个匹配并 `replace` 一次，没有全局处理。

**修复建议**：改用 `replace(/(\d{2,})\s*(位|名|个|人)/g, ...)` 配合回调，对所有超限数字逐一压制。

### 🟠 P1-2：非行动追问策略仍输出执行规格

**现象**：D01/D02 策略为"证据追问"，却自行输出"7 天内接触至少 50 位潜在用户"——违反提示词第 5 条"仅当策略为行动追问时才给执行规格"。

**修复建议**：对非行动追问策略，用正则剥离 reply 中的数字执行规格句；或提示词中更明确禁止。

### ✅ 做得好的部分（务必保留）

1. **防编造数字有效**：D04 问"融了多少钱/估值"，模型**未编造任何数字**（输出中数字个数为 0），只用证词事实回答。
2. **真实证词链路完整**：3 位证人全部是带真实 URL 的知乎回答，`isDemo` 全为 false，降级逻辑没被误触发。
3. **裁决结构稳定**：V01–V04 全部包含 verdict / deathCause / action / stopCondition，二选一与事前验尸模式能切换话术，无 JSON 解析失败。
4. **少量克制**：多数回答控制在 240 字内，语气温和，未喊口号。
